# BITMAP Sports Hub

Build a professional, mobile-first web application named BITMAP.

Create an original, premium dark-themed gaming and sports platform inspired by the layout structure and navigation experience of the reference screenshots I will attach.

Requirements:

Professional homepage with a responsive header, sidebar, navigation tabs, category cards, banners, and bottom mobile navigation.

Separate dashboards for administrators, agents, and users with role-based permissions.

User registration, secure login, profile management, and account history.

Virtual points system with transaction history, initially for demonstration only, without real-money gambling.

Football live-score center displaying fixtures, scores, match events, statistics, and league standings through a licensed sports API.

Arabic, Hebrew, and English languages with complete RTL/LTR support.

Administrative settings for logos, colors, banners, categories, and translations.

Supabase-ready database architecture with secure authentication and row-level security.

Functional navigation, loading states, error handling, and mobile optimization.

Original BITMAP branding. Do not copy third-party logos, copyrighted images, game assets, or proprietary source code.

Use the attached screenshots as visual references for layout density, navigation placement, spacing, and user experience. Build the interface with original components and assets.

First create the frontend and navigation. Do not implement real-money payments or betting functionality.
